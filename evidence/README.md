# Evidence checklist

Capture real application behavior after connecting Supabase. No feature screenshots are fabricated or bundled.

- `submission.png`: valid scholar summary and saved Pending record.
- `verification.png`: staff verification and actor/timestamp history.
- `TC01-boundary.png` through `TC05-late.png`: actual checks and reasons.
- `TC06-gate.png`: blocked evaluation/approval of Pending evidence.
- `TC07-validation.png`: duplicate and invalid input messages.
- `TC08-backend.png`: other-scholar empty result and denied privileged operation, not merely hidden buttons.
- `TC09-correction.png` and `TC09-refresh.png`: Returned → corrected → Pending, retained after reload.
- `TC10-renewal.png`: compliant approval, deficient hold, deficient approval denial.
- `dashboard.png`: selected semester counts and search/filter.
- Export or capture the database test run's actual PASS notices.

Never show passwords, session/access/refresh tokens, service-role keys or secret API keys. Provide test-account access privately to the instructor.
